# Data

This directory holds the inputs of the cross-country firm-panel study of the 2018 French single
flat tax. Two classes of input sit here, and the reproduction is organised around the split.

## Class A: public, redistributable (committed, refreshable from the open APIs)

Open Eurostat and related public series, read by the class-A stage of `reproduce.py` without any
licence. Each is refreshed by its acquisition script under `data_download/` (public, keyless).

| file | content |
|------|---------|
| `dividends_cross_country.csv` | household dividends received by country and year, with the 2017=100 index (Eurostat sector accounts, D42, S14) |
| `corp_surplus_2010_2022.csv` | gross operating surplus of non-financial corporations, by country (Eurostat, B2G, S11) |
| `gdp_volume_2010_2022.csv` | GDP in chain-linked volume, by country (Eurostat, B1GQ) |
| `household_flows_fr.csv` | French household financial flows by instrument (Eurostat financial accounts) |
| `house_prices.csv` | house price index (Eurostat) |
| `unemployment_2010_2022.csv` | unemployment rate by country and year (Eurostat) |
| `dividend_tax_rate_2010_2022.csv` | top dividend tax rate by country and year |
| `framing_fr.csv` | long-format public framing series for France (`series`, `year`, `value`, `unit`) |

## Class B: licensed, not redistributable (never committed, gitignored)

Firm-level extracts from Bureau van Dijk Orbis and from Compustat Global, pulled through WRDS.
The underlying data is licensed, so the parquets are not part of the repository and are
regenerated by the acquisition code under `data_download/`, which is itself excluded. The
class-B stage of `reproduce.py` runs only when `data/raw/firm_panel_real.parquet` is present and
otherwise prints a skip notice.

| file | content |
|------|---------|
| `raw/firm_panel_real.parquet` | main Orbis industrial global-format firm-year panel, France and five comparable economies (DE, IT, ES, BE, NL), 2013 to 2022 |
| `raw/firm_panel_2010.parquet` | the same panel extended back to 2010, used for the figures built around the 2013 tax hike (the ratchet and the retained-capital level) |
| `raw/listed_panel.parquet`, `raw/listed_panel_2010.parquet` | Compustat Global listed firms, the negative control on quoted companies |
| `raw/ownership_*.parquet`, `raw/ownership_flags.parquet` | Orbis ownership snapshot, reference-shareholder flags for the heterogeneity cut |
| `raw/panel_<cc>.parquet` | per-country intermediate extracts |

### Firm-panel schema (one row per firm-year)

Columns follow `src/common/schema.py`: `firm`, `country`, `year`, paid-in `capital`, total
`equity` (shareholders' funds), total `assets`, operating `revenue`, long-term debt `lt_debt`,
`loans`, non-current and current liabilities, tangible `fixed_assets`, `employees`, `cash`,
`net_income`, `pretax_income`, and `firm_age` from the incorporation year. Only `src/data/load.py`
knows the on-disk location; the rest of the pipeline is identical whether it reads the real
extract or the synthetic validation panel.

## Synthetic panel

`src/data/simulate.py` writes a synthetic firm panel with a known injected treatment effect, used
by the self-test in `reproduce.py` so the pipeline can be validated without any licensed data.
